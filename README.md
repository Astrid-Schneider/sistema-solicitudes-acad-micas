# sistema-solicitudes-acad-micas
TPI Metodología de Sistemas II - Sistema de Gestión de Solicitudes Académicas

## Descripción

Versión inicial de una aplicación de consola para gestionar solicitudes académicas. Los datos se almacenan en memoria e incluye información ficticia para probar el sistema.

## Requisitos

- Java 21
- Maven 3.8 o superior

## Compilar y ejecutar

```bash
mvn clean compile
mvn exec:java
```

El menú permite registrar estudiantes y solicitudes, consultar y buscar solicitudes, asignar responsables, cambiar estados y mostrar un reporte por estado.
